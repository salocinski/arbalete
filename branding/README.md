# Identité visuelle d'Arbalète

Sources graphiques du logo (ARB-127), validées par le mainteneur.

| Fichier | Rôle |
|---|---|
| `logo-source.jfif` | Image d'origine du logo |
| `logo-1024.jfif` | Logo en 1024 × 1024 |
| `icone-16x16.ico`, `icone-32x32.ico`, `icone-48x48.ico`, `icone-256x256.ico` | Icônes Windows à une taille, sources de l'icône de l'application |

L'icône utilisée par l'application est `arbalete-browser/resources/icone.ico`. Elle réunit les quatre tailles
ci-dessus en un seul fichier (en-tête ICO et images DIB copiées telles quelles, sans nouvel encodage).
Si une source change, refaire cette fusion et remplacer `icone.ico`.

Les images ont été générées avec Gemini (Google), puis retenues par le mainteneur.
